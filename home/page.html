Potter Service Gaming

More than a server list.

The Game Launcher is being built as a home for the Potter Service gaming community. Each server can have its own identity, artwork, information, status, and connection options while the launcher handles the native features behind the scenes. As the hub grows, new games, worlds, tools, and community features can join it without turning the launcher into a cluttered list.
